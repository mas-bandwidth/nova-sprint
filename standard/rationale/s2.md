# s2. Cards and briefs (rationale)

Status: pending. The section's reasons are written with it.

## R-MINIMAL-DEPS (H7)

The owner, 2026-10-18: "Dependencies are the minimal lightest dependencies that are still
correct with only a small amount of risk, never entirely in serial for a work stream, unless
there is no other way." A hard need holds a card in waiting until its need lands; a stream whose
every card needs the one before it lands one card per read-and-land cycle however wide the fleet
is. An order (LAND-AFTER) keeps the landing order without holding the deal. The code today has no
lint for an unreasoned chain and no per-stream chain line: two divergences name
sprint-spec-fix-minimal-deps-lint, one for the refusal (owed `./cmd/nova-sprint
TestAFullySerialStreamWithoutReasonsIsRefused`) and one for the per-stream line of the longest
chain against the card count (owed `./cmd/nova-sprint TestStreamsPrintsTheLongestHardChain`, the
name that card's DONE-WHEN gives). The clause that a need is written only where the card cannot
compile or run without it is the writer's judgment; the refusal of an unreasoned chain is the
check that holds it.

## R-LINT-ON-ADD (H8)

The owner, 2026-10-18: "Card lint is always run on new cards." Today (2026-10-18, read from
`cmd/nova-sprint`): `add` (one brief, `--brief-file`, `--brief-dir`, `--replaces`) runs the child
rules lint (`lintBriefReads`) and the card checks (`holdCardChecks`); a `brief` edit and `recut
--brief-file` run the child rules lint but not the card checks; `twin` runs neither; the machine's
own cards (`promote_red.go`, `quack.go`) run the child rules lint only. No flag skips the lint.
"The full card lint" in the row is both halves, the child rules lint and the card checks,
because a path that runs only one of them admits a brief the other refuses. `add --brief` (the brief
by flag) and `add --brief-file` are pinned by `TestAddRefusesABriefThatFailsTheCardLint`; add's
card checks by `TestAddHoldsABriefToTheCardChecks`;
`cmd/nova-sprint/spec_admit_lint_test.go` (`TestEveryAdmitPathRefusesALintFailingBrief`) pins
the child rules lint on add by flag, by file, by directory and replacing, on a brief edit and on a
recut; each path that does not (the twin, the machine's own cards, and the card checks on a brief edit
and a recut) is a divergence owed a test by sprint-spec-fix-lint-on-every-admit.
