## R-CHECK-BEFORE-START (H9)

The owner, 2026-10-18: "Sprint check is always run before starting a sprint." `start`
(`setMachine` in `cmd/nova-sprint/run.go`) runs the check and refuses on a violation; the gate
carries DO NOT REMOVE WITHOUT GLENN'S EXPLICIT PERMISSION and no flag skips it. `run` does not
start the machine. Of the card checks (`check cards`), the needs check is a gate: `startNeedsGate`
computes the unresolved needs live and refuses a start while a need is missing or held, though the
check record is clean (v1.2.17; `tla/NeedsBlocked.tla` StartOnlyResolved); the needs gate is off on
a mem twin unless a test arms it. Every other card check only warns (`startCardCheckGate` returns
0). The sprint check (`st.Check`) runs on every store. Pinned by
`TestStartRefusesWhileCheckFindsAViolation`, which plants a violation, and
`TestStartRefusesAHeldNeedAfterACleanCheck`, which plants a held need after a clean check; the gate refuses on any need
`sprint.TableUnresolved` returns, and `TestCheckCardsNamesEachUnresolvedNeed` (internal/sprint)
holds that it returns each of the five reasons (absent, dropped, unknown stream, held, cycle). The first
cold read of this card found the row said every card check only warned while its second pin shows
the held need refusing; the row now states the needs gate.

## R-PLAYBOOK (H12)

The owner, 2026-10-18: "The coordinator must always refresh the playbook so they know how to
operate the sprint machine." `nova-sprint help playbook` prints the coordinator's playbook
(`docs/COORDINATOR-PLAYBOOK.md`, compiled in), held to the verb table by
`TestHelpPlaybookPrintsTheCoordinatorPlaybook` and `TestThePlaybookNamesOnlyRealVerbsAndUsageLines`.
The push that arms a coordinator's hook is nova-hook's (nova-tools) and names the playbook since
card sprint-spec-fix-armed-push-names-playbook landed (2026-10-19): pinned external,
`./cmd/nova-hook TestACoordinatorArmedPushNamesThePlaybook` on nova-tools sprint/v17. A session
start arms the hook (the playbook's section 1), so that push covers both moments. That the
coordinator then reads it is the coordinator's own act and nothing checks it: a divergence names
sprint-spec-fix-playbook-read-enforced (not yet a card) and its owed test, a gate that holds the
coordinator's verbs after each arm until the playbook has been printed to it.
