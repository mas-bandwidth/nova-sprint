# s12. The machine: start, stop, epochs and playbooks

Status: pending

Scope: how the machine starts, stops and clears to a new epoch, the gates that hold each, and the playbooks that tell each seat how to operate.

## Hard rows

These rows are the owner's and bind while the rest of the section is pending.

<a id="R-CHECK-BEFORE-START"></a>
**NS-12.1 R-CHECK-BEFORE-START.** (hard) The start verb MUST run the sprint check (the check of the store's rules) on every store before it starts the machine, and MUST refuse to start, writing nothing, on any violation that check finds. The card checks the start verb also runs are warnings and do not refuse. The start verb MUST NOT offer a flag that skips the sprint check, and the gate MUST NOT be removed.

<a id="R-PLAYBOOK"></a>
**NS-12.2 R-PLAYBOOK.** (hard) The coordinator MUST read the coordinator's playbook (`nova-sprint help playbook`) at the start of every session and every time its hook is armed or armed again; the push that tells a coordinator its hook is armed MUST name the playbook; and the playbook MUST quote only verbs and usage lines the binary has.

<a id="R-WORKER-PLAYBOOK"></a>
**NS-12.3 R-WORKER-PLAYBOOK.** (hard) A verb MUST print the worker playbook, which tells a worker how to take, work, read and finish cards, including the details of each harness it may run under; every worker MUST read it before it takes its first card of a session.
