## Score: 7/10

As the AI that is using this tool right now, I was dealt this card, read the JOB.md, and will finish with its verb. The verb surface and the enforcement are excellent: every `help <verb>` table is a uniform four-field contract (`who`/`up`/`refuses when`/`next`), every refusal is one line that names the one command that fixes it, and the tool itself enforces hook-order, commit identity, and DONE-WHEN-as-one-argv instead of trusting the model to remember. That is genuinely written *for* an agent. It is not 10 because the cold-start promise is not real for a lone AI: nothing in the card carries the work (my JOB.md has kind/repo/base/checkout/paths/done-when but not the task prose or the TEST — that reached me only through the deal, not the job directory), there is no documented way to rehearse the acting verbs against a throwaway store, and this very review card's `done-when` gate checks only two of the five sections the rubric grades. When a cold AI can go from an empty fleet to a landed card with the card self-contained and the gate honestly enforcing the rubric, it is 10.

## What is good

- **`help <verb>` is the best artifact in the tool (verbs/help.go).** I read `help` and then `help take`, `help finish`, `help read`, `help show`, `help version`. Every table is the same four lines a cold AI needs: `who:` (who may run it), `up:` (what must exist first), `refuses when` (each refusal names its one fix), and a closing `next:` line. `help version` even ends `next: nova-sprint version ...`. Uniform across every verb; this alone is most of the way to "an AI that has never seen it".
- **Refusals are one line, name the fix, and use meaningful exit codes (CORRECT-USE "The one rule").** I ran `nova-sprint` with no arguments and got `NEXT this process has no sprint credential / next: run under nova-secrets exec --only NOVA_SPRINT_PG_PASSWORD,NOVA_BUS_PASSWORD -- nova-sprint ...` — exit 0, actionable, not a wall. Running `check` cold got `CHECK RED` lines each naming its own fix, then `SPRINT REFUSED check: 3 lines are red; ...` — exit 1. The `SPRINT REFUSED <verb>: <not true>: <fix>` shape holds.
- **The deal message and receipts are self-carrying.** `take` prints the full brief and ends `next: nova-sprint finish <id>@<gen> --head <sha> ...`; `finish`/`read` each print one `FINISHED`/`READ` line. Nothing has to live in a model's memory between steps (PLAYBOOK-WORKER §Work a card).
- **Enforcement is in the tool, not the AI.** Hook-before-acting, the single git identity with author-email checks on `finish`, DONE-WHEN-as-one-argv, and the chooser lock are all refused by name, not hoped for (CORRECT-USE; LAYER-6 §3).
- **The project knows its cold-start bar and is measuring it.** The dogfood gate is explicit: "an AI with no memory ... takes a fresh fleet from zero to a running sprint using only docs/README.md and the tool's own help, and then does it again" (SETUP §4). The `Built:` notes in LAYER-6 and CORRECT-USE track shipped vs owed — unusual honesty.
